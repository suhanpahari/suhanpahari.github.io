# sohampahari.github.io

Personal academic homepage of **Soham Pahari**.

Built with [Jekyll](https://jekyllrb.com/) using the
[academic-homepage](https://github.com/luost26/academic-homepage) template.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then open http://localhost:4000.

## Editing content

| What | Where |
| --- | --- |
| Name, bio, photo, links, education, experience, awards | `_data/profile.yml` |
| Navigation bar | `_data/navigation.yml` |
| Homepage section toggles | `_data/display.yml` |
| Author name highlighting | `_data/authors.yml` |
| Publications (one file per paper) | `_publications/<year>/` |
| News / updates feed | `_news/` |
| Showcase cards | `_showcase/` |
